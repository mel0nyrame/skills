# Query existing knowledge

Read the [search contract](search.md) before searching. Derive short terms from the question, retaining complete identifiers. Try aliases and alternate terms before reporting absence. Read returned current topics; ranking locates passages rather than verifying facts. Pin related reads/searches with the returned `--revision`; refresh related material if it changes. Keep dates, versions, applicability and uncertainty in the answer.

Select additional reading only when its condition applies:

| Condition | Read |
| --- | --- |
| The answer needs a topic's linked term definition | [Glossary use](glossary.md#use-in-topics-and-answers); follow the relevant entry |
| The user requests an explanation adapted to their existing knowledge | [Profile use](profile.md#use-in-answers); find relevant current profile evidence |

Otherwise, answer from the topic and explain necessary prerequisites normally. A query uses existing evidence. Saving new glossary or profile claims requires a capture or maintenance request.
