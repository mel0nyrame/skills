# Contextual glossaries

A contextual glossary defines terms within a subject or project. For finding and publishing glossary topics, read [resource storage](personalization.md).

## Capture and maintain

Record resolved, reusable terms. Keep each canonical term, short definition, context, useful aliases, and source link together. Link extended explanations to their owning topics. Create a glossary only when there is a supported entry; group one coherent subject and split when contexts give the same word different meanings.

Treat `agent = harness + AI` as local shorthand only when the source establishes that meaning. Define or link its constituent terms. Resolve conflicting definitions by context or retain the disagreement. Correct affected meanings under the existing source and publication rules. When a definition changes an existing profile's meaning, follow [profile corrections](profile.md#capture-and-maintain) for the affected claims.

## Use in topics and answers

Introduce a necessary term with a short local explanation and a direct glossary-entry link; the entry can own its extended definition. Keep the topic's essential background, causal reasoning, examples, and operating conditions. Follow its prerequisites without the chat and repair missing or circular definitions before publication. These rules complete the existing standalone reading check rather than add a separate review process.
