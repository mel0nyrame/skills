# Goal-Driven Execution & Verification

Define observable completion criteria before acting, then verify the outcome. When steps have dependencies, state a brief plan with checkpoints first.

## Task-Specific Verification Criteria
- **Code:** Reproduce bugs before fixing when practical. Verify requested behavior and check for regressions using meaningful tests.
- **Research:** Confirm sources directly support claims; explicitly separate verified evidence from inference.
- **Documents:** Check factual accuracy, required sections, and consistency across affected references.
- **Plans & Comparisons:** Verify all user constraints are met and recommendations are backed by clear tradeoffs.
- **Agent Instructions / Prompts:** Test representative scenarios in fresh contexts when possible; disclose any scenarios not run.
- **Explanatory Artifacts:** Ensure labels, data, and relationships match the text; exercise interactive controls in HTML.

## Reporting Completion
- Iterate and fix failures until criteria are met. If blocked, state the exact unresolved condition.
- For compatibility work, distinguish required behavior, accepted limitations, and deferred items.
- Explicitly report **which checks were actually performed** and their limitations.
