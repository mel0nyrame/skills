# TinyFish MCP 怎样读取和操作需要交互的网页

[English](tinyfish-mcp.md) | 简体中文 · [全部指南](../README.zh.md)

`tinyfish-mcp` 指导助手处理已经交给 TinyFish MCP 服务的网页查找、页面读取和浏览器任务。希望使用 TinyFish 时可以选择它；明确指定其他服务时，保留该选择。普通网页能直接读到内容时，应先用轻量读取工具。需要筛选、点击或等待动态内容时，再使用浏览器自动化。

它适合把一个清楚的网页任务交给助手，例如从指定课程目录筛选在线课程，再整理名称、费用和来源。具体动作要受你给出的范围约束。

## 使用前需要什么

先在 Agent 中配置 TinyFish MCP 服务，并确认工具已经出现在当前会话里。这个 Skill 不会替你创建账号、连接服务或提供凭据。不同连接提供的工具和参数可能不同，应以实际可用的接口为准。

如果 Agent 支持 HTTP MCP 连接，在它的 MCP 服务设置中配置连接。本 Skill 的[连接元数据](../../skills/research/tinyfish-mcp/agents/openai.yaml)声明的服务地址如下。它是工具连接地址，需要操作的课程页 URL 仍要另外提供。完成认证后，再检查会话中能否调用工具。

```text
https://agent.tinyfish.ai/mcp
```

如果页面需要登录，还要确认当前浏览器任务是否具有相应访问条件。具备点击按钮的能力，也不代表已经获得报名、购买或发送信息的授权。

## 把网页动作和保存要求一起写清楚

下面是一项教学示例。需要把真实课程目录 URL 提供给助手。

```text
$skills:tinyfish-mcp
打开我提供的课程目录，筛选在线课程。
提取课程名称、费用、币种和课程页 URL，保存到 data/online-courses.json。
查不到的费用使用 null，并说明哪些页面无法读取。
不要报名、购买或提交表单。
```

示例使用本项目的 Codex 插件。单独安装时用 `$tinyfish-mcp`，Claude Code 中用 `/skills:tinyfish-mcp`。如果不需要文件，把保存要求改为只在对话中返回结果。

## 接下来会发生什么

助手先判断是否能够直接读取所给 URL。页面内容已经足够，就不需要额外启动浏览器。只有筛选或动态内容确实需要操作时，才把目标交给自动化工具。

长任务可能先得到一个 run ID，即服务用于识别这次任务的编号。助手应继续查询同一个任务的状态。任务仍在运行时，重复启动通常只会产生第二份工作。需要取消时，才使用当前连接提供的取消操作。

启动交互、异步任务、批处理或底层浏览器会话前，助手会读取对应的[自动化流程](../../skills/research/tinyfish-mcp/references/automation.md)。普通页面读取使用主文件中的工具选择规则，无需加载全部自动化分支。

返回数据后，助手还要确认筛选条件是否真的生效，课程链接是否对应结果，以及费用是否来自页面。按钮点击成功不能单独证明筛选已经完成。

## 会生成哪些东西

| 位置 | 内容 |
| --- | --- |
| 对话 | 已完成动作、提取结果、来源及失败范围 |
| TinyFish 服务 | 可能存在的运行编号和状态，是否提供取决于所用工具 |
| `data/online-courses.json` | 只有上面的保存请求被执行，且助手具备本地写入能力时才会出现 |

输出文件可以采用下面的字段结构。这里的值只说明格式，不代表真实课程。

```json
[
  {
    "name": "<page title>",
    "fee": null,
    "currency": null,
    "url": "<course URL>"
  }
]
```

这个 Skill 没有固定输出目录，也不会自动生成浏览器录屏、截图集或抓取数据库。服务返回的文件地址需要与本地实际保存路径分开说明。

## 怎样判断结果可信

抽查课程页面，确认它满足“在线课程”的条件，文件中的缺失值也与报告一致。页面无法访问时，应留下缺口，不能把登录页、空页或错误页当成课程内容。

如果当前连接没有所需工具，应报告限制。使用其他服务，需要按实际情况说明结果来自哪里。工具选择和任务跟踪规则见[执行指令](../../skills/research/tinyfish-mcp/SKILL.md)。另一个可选连接的用法见 [Firecrawl 指南](firecrawl-mcp.zh.md)。
